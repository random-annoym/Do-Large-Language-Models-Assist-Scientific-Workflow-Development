# Do-Large-Language-Models-Assist-Scientific-Workflow-Development

This repository is the replication package for the paper **“Do Large Language Models Assist Scientific Workflow Development?”** It contains the prompt sets, workflow lists, generated workflow materials, background prompts and responses, and other supporting resources used in the study. The repository is organized around the main stages of the evaluation to support inspection and reuse.
## Repository Contents

The repository currently includes the following main items:
- **Prompts and Generated Workflows**  
  Contains the workflow-generation prompts used in the study and the corresponding workflows produced by the evaluated LLMs.

- **Workflow Specific Background Prompts and Responses**  
  Contains workflow-specific background questions and the corresponding LLM responses used to assess contextual understanding before workflow generation.

- **fundamental_and_background_prompts**  
  Contains the fundamental prompts and platform/background prompts used to evaluate LLM understanding of scientific workflows, workflow systems, and related concepts.

- **1. Case Studies Workflow List.pdf**  
  Provides the list of benchmark/case study workflows used in the evaluation.

## Purpose of the Replication Package

This replication package supports the study by making available the core materials used in the evaluation of LLMs for scientific workflow development. In particular, it allows readers to inspect:

- the benchmark workflow list,
- the prompt sets used across different evaluation phases,
- the workflow-specific background questions,
- and the generated workflow materials.

## Study Focus

The paper investigates whether Large Language Models can assist scientific workflow development. The evaluation examines multiple aspects of LLM capability, including:

- understanding fundamental workflow concepts,
- understanding background concepts related to workflow platforms,
- answering workflow-specific background questions,
- and generating workflows from prompts.

## How to Use This Repository

A suggested way to navigate the repository is:

1. Start with **`1. Case Studies Workflow List.pdf`** to understand the workflows included in the study.
2. Review **`fundamental_and_background_prompts`** to see the general conceptual prompts.
3. Review **`Workflow Specific Background Prompts and Responses`** to examine the workflow-level contextual questions and responses.
4. Review **`Prompts and Generated Workflows`** to inspect the workflow-generation prompts and resulting outputs.

## Notes

This repository is intended as a replication package for the paper and is organized to make the study materials easy to inspect. The structure reflects the main phases of the evaluation and the supporting benchmark information available in the repository.
